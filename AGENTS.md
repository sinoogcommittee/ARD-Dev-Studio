# Project Instructions

- Treat this folder as the source of truth for the Anthony Riel C. Diango portfolio website.
- Read `PROJECT_BRIEF.md`, `CONTENT.md`, `DESIGN_SYSTEM.md`, and `ARCHITECTURE.md` before making project decisions.
- Build with React, Tailwind CSS, and Supabase. Use VS Code as the intended editor.
- Make the 16 live projects the center of the experience. Prioritize a polished, motion-rich gallery that helps prospective clients and employers quickly assess the work and get in touch.
- Use only facts, credentials, contact details, and project capabilities documented in `CONTENT.md`. Do not invent testimonials, client outcomes, project metrics, availability, or social accounts.
- Keep motion purposeful, smooth, responsive, and respectful of `prefers-reduced-motion`. Keep navigation, project links, and contact actions usable without animation.
- Keep project information in structured data separate from presentation. Avoid adding dependencies when native CSS or browser APIs are sufficient.
- Keep Supabase secrets server-side or in environment variables; never commit credentials. Follow `ARCHITECTURE.md` for the contact form and graceful fallback.
- Make the layout work on mobile, tablet, and desktop; use semantic HTML, keyboard access, visible focus, and accessible contrast.
- Do not replace or omit supplied live project URLs. If a link is unavailable, flag it for review instead of silently substituting a URL.
